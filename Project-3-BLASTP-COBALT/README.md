# Project 3 — Protein Sequence Similarity Analysis Using BLASTP and COBALT

## Overview

This project investigates the sequence similarity of hen egg-white lysozyme using protein sequence analysis tools.

The query protein sequence was analysed using NCBI BLASTP to identify similar protein sequences. NCBI COBALT was also explored as a multiple sequence alignment tool.

## Objectives

- Identify similar protein sequences using BLASTP
- Understand sequence identity and similarity
- Interpret BLAST scores and E-values
- Examine gaps in sequence alignments
- Explore multiple sequence alignment using COBALT

## Key BLASTP Finding

The query sequence showed a 100% identical match across 129 aligned residues with a hen egg-white lysozyme sequence from Gallus gallus.

Highly similar lysozyme sequences from other avian species were also identified.

## Tools Used

- NCBI Protein BLAST (BLASTP)
- NCBI COBALT
