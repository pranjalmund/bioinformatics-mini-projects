# Project 2 — Comparative Structural Analysis of Lysozyme

## Overview

This project compares hen egg-white lysozyme in two structural contexts: PDB 1FDL, where lysozyme is bound to an antibody, and PDB 1AKI, where lysozyme is present as a standalone protein structure.

The aim was to determine whether the overall three-dimensional structure of lysozyme remains broadly similar in these two contexts.

## Topics Covered

- Comparative protein structure analysis
- Protein sequence verification
- Three-dimensional protein structure
- X-ray crystallography
- Structural resolution
- Introduction to RMSD

## Structures Compared

**PDB 1FDL:** Antibody-bound hen egg-white lysozyme

**PDB 1AKI:** Hen egg-white lysozyme structure

Both lysozyme chains contain 129 residues.
