# Project 1 — Structural Analysis of PDB 1FDL

## Overview

This project focuses on the structural analysis of PDB entry **1FDL**, which represents an antibody–antigen complex between **Fab D1.3** and **hen egg-white lysozyme**.

I explored the structure using the **RCSB Protein Data Bank** and **Mol\*** molecular visualization tools to understand the organization of the protein chains and the overall arrangement of the complex.

## Biological Question

How is hen egg-white lysozyme organized within the 1FDL antibody–antigen complex, and what can be observed from its three-dimensional structure?

## Structure Information

| Feature | 1FDL |
|---|---|
| Structure | Fab D1.3–hen egg-white lysozyme complex |
| Experimental method | X-ray diffraction |
| Resolution | 2.50 Å |
| Protein chains | 3 |
| Lysozyme chain | Chain C (author chain Y) |
| Lysozyme length | 129 residues |

## Tools Used

- RCSB Protein Data Bank
- Mol*
- Protein structure visualization

## What I Did

1. Retrieved PDB entry **1FDL** from the RCSB Protein Data Bank.
2. Examined the structure using Mol*.
3. Identified the different protein chains present in the complex.
4. Selected the hen egg-white lysozyme component.
5. Examined its three-dimensional structure in relation to the antibody.
6. Recorded structural observations for the project report.

## Key Observation

The 1FDL structure contains an antibody fragment bound to hen egg-white lysozyme.

The lysozyme component is a **129-residue protein chain** and can be examined separately from the antibody using the Mol* visualization interface.

The structure also demonstrates how a protein antigen can form a defined molecular complex with an antibody.

## What I Learned

This project helped me become familiar with:

- Reading basic information from a PDB entry
- Understanding protein chains in a structural model
- Identifying a specific molecule and chain in Mol*
- Interpreting a protein structure in three dimensions
- Distinguishing structural observations from quantitative measurements

## Limitations

This project was primarily a **qualitative structural analysis**.

I did not calculate structural similarity, RMSD, or residue-level interaction energies in this project. Those types of analyses require additional computational methods and are explored in later projects.

## Next Step

A natural follow-up question is whether the three-dimensional structure of lysozyme changes when it is bound to the antibody compared with lysozyme in its free state.

This motivated the comparative analysis performed in **Project 2**.
