# Project 1 — Structural Analysis of PDB 1FDL

## Overview

This project focuses on the structural analysis of PDB entry 1FDL, which represents an antibody–antigen complex between Fab D1.3 and hen egg-white lysozyme.

The structure was explored using the RCSB Protein Data Bank and Mol* molecular visualization tools.

## Topics Covered

- Protein Data Bank (PDB)
- Protein structure interpretation
- Protein chains
- Molecular visualization
- Antibody–antigen complexes
- Structural biology
