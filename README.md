# Bioinformatics Mini-Projects

A growing portfolio of hands-on bioinformatics and computational biology projects, developed while building my foundation for research in computational biology and bioinformatics.

## About This Repository

This repository documents my learning through small, reproducible projects rather than only certificates or tutorials.

I am using these projects to build practical skills in:

- Protein sequence analysis
- Structural bioinformatics
- Sequence alignment
- Comparative analysis
- Molecular visualization
- Phylogenetic analysis
- Python programming for biological data
- Research-oriented computational thinking

Each project starts with a biological question, uses publicly available biological data and computational tools, and ends with an interpretation of the results.

## Learning Approach

My goal is not simply to learn how to operate individual bioinformatics tools.

For each project, I am trying to understand:

1. What biological question am I asking?
2. What data do I need?
3. Why is a particular computational method appropriate?
4. What does the output actually mean biologically?
5. What are the limitations of the analysis?
6. What could be investigated next?

This repository will therefore evolve as my computational and research skills develop.
