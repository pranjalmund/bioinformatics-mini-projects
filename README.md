# Bioinformatics & Computational Biology Portfolio

A collection of progressive bioinformatics and computational biology projects developed to build practical skills in sequence analysis, structural biology, transcriptomics, programming, and reproducible research.

## About This Portfolio

This repository documents my transition from a Biotechnology background toward computational biology and bioinformatics.

The projects are designed around a simple progression:

**Biological question → Computational analysis → Biological interpretation → Limitations → Next research question**

Rather than focusing only on learning individual software tools, the portfolio emphasizes understanding what the computational results mean biologically.

## Research Approach

Each project follows a research-oriented structure where possible:

1. Define a biological question
2. Identify appropriate data
3. Select a computational method
4. Perform or interpret the analysis
5. Examine the biological significance
6. Identify limitations
7. Suggest possible follow-up questions

This approach is intended to develop computational reasoning rather than simply produce tool-based outputs.

---

## Scientific Honesty & Reproducibility

An important principle of this portfolio is distinguishing between:

- Results independently generated during analysis
- Results obtained from public databases
- Findings reported by published studies
- Biological interpretations or hypotheses

Published numerical findings are not presented as independently reproduced results unless the analysis was actually regenerated.

Where an analysis has limitations, those limitations are documented rather than hidden.
